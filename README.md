# 羽毛球比赛小程序

一个功能完整的羽毛球比赛管理小程序，支持比赛创建、管理和分数计算。

## 功能特性

### 🏸 创建比赛
- 设置比赛名称、时间、地点
- 选择比赛类型（单打、双打、混合双打）
- 设置最大参赛人数
- 添加和管理参赛选手

### 📋 比赛列表
- 查看所有比赛信息
- 按状态筛选（全部、报名中、进行中、已结束）
- 比赛状态管理（开始、结束、删除）
- 比赛详情查看

### 👤 个人中心
- 用户信息管理
- 比赛统计数据
- 比赛记录查看
- 分数计算器
- 数据导出和清除

## 页面结构

```
pages/
├── create-match/     # 创建比赛页面
├── match-list/       # 比赛列表页面
├── profile/          # 个人中心页面
└── index/            # 首页（可重定向到创建比赛）
```

## 技术特点

- 使用微信小程序原生开发
- 本地数据存储（wx.setStorageSync）
- 响应式UI设计
- 模块化代码结构

## 使用方法

1. 在微信开发者工具中导入项目
2. 编译并预览
3. 使用底部标签栏切换不同功能页面

## 数据存储

比赛数据存储在本地存储中，包括：
- 比赛基本信息
- 参赛选手列表
- 比赛状态和进度
- 用户偏好设置

## 后续扩展

- 实时分数记录

- 社交分享功能
- 云端数据同步
